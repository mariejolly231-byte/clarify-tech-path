# Summit Flow Altitude, version tableau Excalidraw

Thème de projection Summit Flow, calé sur le schéma « Modèle, inférence, harnais » : fond blanc, trait à main levée, aplats pastel doux qui débordent un peu du trait, comme un surligneur. Le teal Summit Flow est la couleur principale. Pas de rouge, pas de dégradé.

## Palette

| Token | Hex | Rôle |
|---|---|---|
| `--teal` | `#0B4F5C` | Couleur principale : titres, numéros, sommaire, progression |
| `--ink` | `#1F2A2E` | Trait et texte courant |
| `--muted` | `#5C6366` | Texte secondaire, sources |
| `--line` | `#CBD3D3` | Traits légers, pointillés |
| `--paper` | `#FFFFFF` | Fond |
| `--mint` | `#D6F1E6` | Pastel principal : agent, étape en cours, surligneur par défaut |
| `--sky` | `#DCEEFA` | Assistant, information |
| `--lemon` | `#FFF3C4` | Automatisation, vigilance, encadrés « le saviez-vous » |
| `--blush` | `#FCE4E8` | Limites, réserves |
| `--tealp` | `#D3E8EA` | Fond doux teal |

Contrastes : encre sur tous les pastels au-dessus de 11:1, teal au-dessus de 7:1, gris secondaire au-dessus de 4,8:1.

## Typographie

- **Titres, annotations, schémas** : Excalifont, la police d'Excalidraw.
- **Texte courant** : Bricolage Grotesque 500.
- Proxima Nova reste la police de marque pour les supports imprimés et le web sous licence.

## Interactivité

Révélations pas à pas à la flèche droite, schémas tracés à l'écran, cartes à classer, outil de décision, minuteurs, zones à remplir en direct. Tout reste immobile si l'ordinateur demande moins d'animations.

## Règles de contenu

Une idée par slide. Chaque chiffre porte sa source dans un encadré ampoule (voir `SOURCES.md`). Les situations de Maison Lagarrigue viennent de la proposition et sont présentées comme des pistes à confirmer. Pas de nom de personne, pas d'emoji.
